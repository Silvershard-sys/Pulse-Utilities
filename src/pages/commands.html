Bot Commands

Every command Pulse Utilities currently supports. Slash commands shown below; most also work as prefix commands.

🛡️ Moderation & Automod

/ban

Ban a member from the server

Usage:

/ban <user> [reason] Requires: Ban Members

/kick

Kick a member from the server

Usage:

/kick <user> [reason] Requires: Kick Members

/unban

Unban a user by ID

Usage:

/unban <user_id> Requires: Ban Members

/softban

Kick a member and purge their recent messages

Usage:

/softban <user> [reason] Requires: Ban Members

/timeout

Timeout a member

Usage:

/timeout <user> <minutes> [reason] Requires: Moderate Members

/warn

Warn a member

Usage:

/warn <user> <reason> Requires: Moderate Members

/warnings

View a member's warnings

Usage:

/warnings <user> Requires: Moderate Members

/clearwarnings

Clear all warnings for a member

Usage:

/clearwarnings <user> Requires: Moderate Members

/purge

Bulk delete recent messages in this channel

Usage:

/purge <amount> Requires: Manage Messages

/lock

Lock a channel, preventing @everyone from sending messages

Usage:

/lock [channel] [reason] Requires: Manage Channels

/unlock

Unlock a previously locked channel

Usage:

/unlock [channel] Requires: Manage Channels

/slowmode

Set slowmode for this (or another) channel

Usage:

/slowmode <seconds> [channel] Requires: Manage Channels

/nickname

Force-set (or reset) a member's nickname

Usage:

/nickname <user> [nickname] Requires: Manage Nicknames

/automod

Toggle and tune automod filters: spam, mass mentions, invite links

Usage:

/automod toggle | config | status Requires: Manage Server

/auditlog

Pull recent moderation actions for this server

Usage:

/auditlog [amount] [include_joins_leaves] Requires: Moderate Members
✅ Verification

/verify-setup

Configure the verification channel, role, and message in one step

Usage:

/verify-setup <channel> <role> [message] Requires: Manage Server

/verify-status

Check if a member is verified

Usage:

/verify-status [user] Anyone can use

/reverify

Remove a member's verified role and force them back through the gate

Usage:

/reverify <user> Requires: Manage Server
⚙️ Configuration

/setup

Configure all core settings from one interactive panel

Usage:

/setup Requires: Manage Server

/config

Configure the log channel, welcome channel, or prefix individually

Usage:

/config logchannel | welcomechannel | prefix Requires: Manage Server

/prefix

View or change the prefix used for prefix commands

Usage:

/prefix [new_prefix] View: anyone · Change: Manage Server
🖼️ Embeds

/embed create

Send a new embed

Usage:

/embed create <title> <description> [color] [channel] Requires: Manage Messages

/embed edit

Edit an embed the bot previously sent

Usage:

/embed edit <message_id> [title] [description] [color] Requires: Manage Messages

/embed delete

Delete an embed the bot previously sent

Usage:

/embed delete <message_id> Requires: Manage Messages

/announce

Quickly post an announcement embed without the full embed builder

Usage:

/announce <message> [channel] Requires: Manage Messages
